# Rust Util — состояние требований

- [x] Статический HTML/CSS/JavaScript без Flask, SQLite и runtime-фреймворков. Три страницы: чекер, рейд, переработка. Относительные пути и прямые страницы в подкаталоге GitHub Pages.
- [x] SteamID64: битовая проверка, копирование, профиль и инвентарь. Без внешнего API нет выдуманных ников, аватаров, часов, возраста и статуса. Ключей в клиенте нет.
- [x] PNG/JPG до 16 МБ и 20 млн пикселей: выбор, drag-and-drop, превью, браузерный OCR, прогресс, отмена и ошибки. Скриншоты не отправляются на сервер. Native worker очищается также при отмене инициализации; общий лимит OCR — 120 секунд.
- [x] Локальный трекер: добавление без дубликатов, заметки, удаление, сохранение, экспорт/импорт; до 1000 записей. Фильтры включают неизвестный статус. Живой статус обновляется только через внешний API, старый статус сбрасывается при перезапуске.
- [x] Рейд-модель: сооружение, допустимые материалы, количество 1–999, HP, взрывчатка, сера, порох, компоненты. Округление каждой отдельной цели, сортировка по сере, учёт партий крафта, 14 целей и 6 боеприпасов.
- [ ] Точное совпадение рейд-модели с текущими игровыми расходами. Закреплённый снимок 10 октября 2026 даёт для stone wall 13 satchel вместо 10 в Wiki, 200 explosive ammo вместо 185 с SAR. Ограничение показано прямо в UI и README; результат не выдан за точный игровой список закупки. Полный разбор — docs/DATA.md.
- [x] Переработка: поиск, более 60 доступных предметов (1001 записей в полном снимке, скрытые записи не показываются), корзина, агрегация ожидаемых ресурсов, оценка последовательного времени и копирование. Источники, полная прочность, дробный выход, powergrid и условия расчёта указаны.
- [x] Адаптивная навигация, сворачивание с сохранением, доступность разделов на мобильном. Тёмная/светлая тема, размеры текста и RU/EN сохраняются локально. Оригинальные игровые названия в каталоге — английские.
- [x] Инженерный интерфейс: нейтральные панели, #CD412B, тонкие границы, компактная типографика и моноширинные числа; семантика, фокус, подписи полей и реальные ошибки. Без эмодзи, градиентов, фиктивного пользователя и декоративных изображений.
- [x] README, источники данных, контракт API, воспроизводимые генераторы и CI-конфигурация. 63 статические проверки и 33 автоматических теста проходят. DOM и жизненный цикл OCR проверены; визуальная/сквозная проверка распознавания реального скриншота не выполнялась.
- [ ] Сохранить проект в отдельный новый GitHub-репозиторий. Публикация Pages и публичная видимость требуют отдельного решения владельца.
